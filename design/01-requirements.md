# 01. 要件定義（確定版）

## システム概要
オフィスの座席配置、従業員の出勤状況、プロフィール、技術スキルを一元管理する Web アプリケーション。
一般公開し、誰でもマスターとして新規登録して試せる（**マルチテナント**）。

## 技術構成
| 項目 | 採用 |
|---|---|
| バックエンド | Python / FastAPI |
| フロントエンド | HTML / CSS / JavaScript（フレームワーク不使用） |
| DB | SQLite（標準ライブラリ `sqlite3`、**生SQL**） |
| ASGI サーバー | Uvicorn |
| パッケージ管理 | pip |
| バージョン管理 | Git / GitHub（`master` ← `develop` ← `feature/*`） |

## ユーザー権限
| 権限 | 説明 |
|---|---|
| マスター | 画面から新規登録すると、自分専用の**組織**が作られる。管理専用でプロフィール・出勤情報は持たず、マップにも表示されない。1組織につき1人（将来は複数にできる設計） |
| 一般ユーザー | マスターが作成する。初回ログイン時にパスワード変更とプロフィール登録を行う |

すべてのデータは組織ごとに分かれており、他の組織のデータは見ることも操作することもできない。

## 機能一覧
| 分類 | 機能 | マスター | 一般 |
|---|---|:-:|:-:|
| 認証 | 新規登録（組織＋マスター） | ○ | |
| | ログイン・ログアウト（画面は共通） | ○ | ○ |
| ユーザー管理 | 一般ユーザーの作成・編集・物理削除、パスワードのリセット | ○ | |
| プロフィール | 初回登録・編集（名前・生年月日・役職・職種・画像・デフォルト座席） | | ○ |
| 技術スキル | 言語 / FW / DB / クラウドと経験年数（職種がエンジニアの場合） | | ○ |
| 出勤 | 出社（座席を選択、デフォルト座席を初期選択）・リモート・退勤、ひとことコメント | | ○ |
| 在席 | 在席中 ⇄ 離席中 | | ○ |
| マップ | フロア・部屋の作成、家具の配置（位置・サイズ・向き） | ○ | |
| | マップの閲覧、アイコンのクリックでプロフィール表示 | ○ | ○ |
| 座席の管理 | 使用中の座席の確認、強制的に空ける | ○ | |
| 候補の管理 | 役職・職種・スキルの候補の一覧 | ○ | |
| 組織の設定 | 組織名の変更、組織の削除（すべてのデータを完全に削除） | ○ | |
| お試し用のサンプル | 空の組織に、オフィスマップと従業員6人（プロフィール・スキル・在席状態つき）を作成 | ○ | |

> 当初の要件にあった「困りごと共有」は、Slack と役割が重なるため削除した（2026-11-06）。

## 決定事項
| 項目 | 決定内容 |
|---|---|
| ログインID | メールアドレス（システム全体で重複不可）＋パスワード |
| 最初のマスター | 公開されている新規登録画面から作成 |
| ユーザーの削除 | 物理削除（関連するデータもまとめて削除） |
| 状態の持ち方 | 日付が変わってもリセットしない。「退勤」で未出勤に戻り、座席が空く |
| ひとことコメント | 残り続ける（本人が変えるまで） |
| 年齢 | 生年月日から自動で計算（日本時間を基準） |
| 座席の重複 | 先に登録した人を優先（後の人は「使用中」のエラー） |
| デフォルト座席 | 複数人が同じ座席を設定できる |
| 画面の更新 | 30秒ごとのポーリング |
| マップの編集 | SVG、ドラッグ＆ドロップ、グリッドに吸着、90度ずつ回転 |
| 家具の種類 | 机・椅子（＝座席）・壁・ドア・その他 |
| 候補の一覧 | 選択式。候補にない名前を入力すると、その組織の候補に自動で追加。組織の作成時に既定の候補（役職・職種・代表的なスキル）を登録 |
| 職種がエンジニア以外 | 技術スキルは登録できない。エンジニアから他の職種に変えると、登録済みのスキルは削除 |
| 人が座っている椅子を削除 | 確認ダイアログを出し、座っていた人を未出勤に戻してから削除 |
| パスワードを忘れた場合 | 一般ユーザーはマスターがリセット。マスター自身は復旧できない（お試し用のため許容） |
| メールアドレスの確認 | 行わない |
| 上限（1組織あたり） | ユーザー50名・フロア5・部屋5（フロアごと） |
| 対応端末 | PC のブラウザのみ（幅 1280px 以上） |
