## S10 マップ
```
┌──────────────────────────────────────────────────────────────────┐
│ 組織名      [マップ] [プロフィール]                  山田太郎 ▼ │
├────────────┬───────────────────────────────────┬─────────────────┤
│ 1F         │                                   │ ■ 自分の状態    │
│  ▸ 執務室A │   ┌──┐ ┌──┐                       │  ● 在席中       │
│    会議室  │   └──┘ └──┘   [机]   ┌──┐         │  座席：1F 執務室A│
│ 2F         │  ┌──┐┌────────┐┌──┐  └──┘         │  [離席][退勤]   │
│    開発室  │  │🙂││   机   ││  │ ...           │  [座席変更]     │
│            │  └──┘└────────┘└──┘               │  コメント：      │
│            │                                   │  [集中してます] │
│            │                                   │ ■ リモート (3)  │
└────────────┴───────────────────────────────────┴─────────────────┘
```
- 状態の色：在席中＝緑、離席中＝オレンジ、リモート＝青（右側の一覧）。未出勤の人は表示しない
- 出社：[出社] → 座席の選択モード（デフォルト座席を強調表示）→ 空いている椅子をクリック → [確定]
- ボタン：未出勤＝[出社][リモート]、出社中＝[離席/在席に戻る][座席変更][退勤]、リモート＝[出社][退勤]
- アイコンをクリックするとプロフィールのポップアップ。30秒ごとに自動で更新
- マスターには右側の操作パネルを表示しない

## S03 初回設定
① パスワード変更 → ② プロフィール → ③ 技術スキル（エンジニアのみ）→ ④ デフォルト座席（スキップ可）

## S22 マップ編集
```
┌──────────┬──────────────────────────────────────┬────────────────┐
│ 部品     │  部屋：[1F ▾][執務室A ▾]  [保存][元に戻す] │ 選択中：机     │
│ [机]     │ ┌ ─ ─ ─ ─ グリッド ─ ─ ─ ─ ┐            │ ラベル [    ]  │
│ [椅子]   │   ┌────────┐  ┌─┐                      │ X [4] Y [6]    │
│ [壁]     │   │  机    │  └─┘                      │ 幅 [6] 高さ[3] │
│ [ドア]   │   └────────┘                         │ 向き [⟲][⟳]   │
│ [その他] │ └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘            │ [削除]         │
└──────────┴──────────────────────────────────────┴────────────────┘
```
- ドラッグ＆ドロップ、グリッドに吸着。右のパネルで数値を細かく調整できる
- 保存していない変更があるときに画面を離れようとすると警告。人が座っている椅子を削除するときは確認ダイアログ

## そのほかの画面
- S11：S03 の②〜④をまとめた編集画面と、パスワードの変更
- S12：「未解決 / 解決済み / 自分の」のタブ、カード形式の一覧、登録・編集のダイアログ
- S20：ユーザーの表、作成ダイアログ（初期パスワードの自動生成）、パスワードのリセット、削除の確認
- S21：フロアごとの部屋の一覧（追加・名前の変更・並び替え・削除）、部屋の大きさ
- S23：使用中の座席の一覧と [強制的に空ける]
- S20・S10（マスター）：フロアも従業員もない組織では「サンプルを作成」の案内を表示
- S25：組織名の変更と、組織の削除（組織名とパスワードを入力するまで削除ボタンは押せない）
- S24：役職 / 職種（エンジニアかどうか）/ スキル（4分類）のタブ

## 共通のUI
- 画面の幅は 1280px 以上を想定
- 入力エラーは項目の下に表示し、成功や失敗のお知らせはトーストで表示
- 409（座席が使用中）の場合は、お知らせを出してマップを最新の状態に更新
